# שלב 5 — חיפוש בוחרים והרשאות

קלפי רגילה מחפשת בוחר המשויך אליה; קלפי נגישה יכולה לחפש כל בוחר קיים.
השרת בודק תשע ספרות, קיום במאגר, שיוך בקלפי רגילה ולבסוף האם הבוחר כבר הצביע.
נוסחי השגיאות וסדר הבדיקות תואמים ל-README. מספרי זהות נשארים מחרוזות.

## הרצה ובדיקה עצמית

עצור את השרת הקודם באמצעות Ctrl+C והפעל מתיקיית הפרויקט:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run-api.ps1
```

פתח `http://127.0.0.1:5080/`. אין שינוי בסכמת המסד או בסיסמאות הקיימות.
התחבר לקלפי רגילה שסיסמתה נקבעה בשלב הקודם. מצא בקובץ people.csv תעודת זהות
עם KalpiId המתאים, חפש אותה ובדוק שהשם והשיוך מוצגים. כפתור אישור מושבת:
עדיין אין שמירת הצבעה. לחץ ביטול ובדוק שחזרת לשדה חיפוש ריק.

חפש בוחר מקלפי אחרת: תוצג ההודעה "הבוחר אינו משתייך לקלפי זה".
התחבר לקלפי נגישה וחפש אותו בוחר: מסך הזיהוי ייפתח.
מספר תקין שאינו במאגר יחזיר "שגיאה מספר הזהות אינו במאגר".
מנהל אינו מקבל הרשאה לנתיב החיפוש של הקלפיות; מעטפות כפולות יתווספו בנפרד.

## אחריות הרכיבים וההרשאות

| קובץ | אחריות |
| --- | --- |
| `Contracts/VoterSearchRequest.cs` | מבנה הקלט: Id בלבד |
| `Models/Voter.cs` | ייצוג פנימי של פרטי הבוחר הדרושים לבדיקה |
| `Data/VoterStore.cs` | קריאה מ-People בשאילתה פרמטרית |
| `Controllers/VotersController.cs` | הרשאת קלפי, אימות מזהה, שיוך ומצב הצבעה |
| `wwwroot/index.html` | טופס חיפוש ומסך זיהוי |
| `wwwroot/js/app.js` | שליחת הבקשה והצגת התוצאה, ביטול וחזרה לחיפוש |

Authentication מזהה את הקלפי. Authorization בודק גם את תפקידה וגם את
שיוך הרשומה: תפקיד Regular לבדו אינו מתיר גישה לבוחר מקלפי אחרת.
השרת קורא את מספר הקלפי מה-Claims המאומתים ולא משדה ששולח הדפדפן.
ההרשאה נאכפת גם בפנייה ישירה ל-API.

`POST /api/voters/search` מבצע קריאה בלבד. POST מאפשר להעביר את תעודת הזהות
בגוף הבקשה במקום בכתובת ובהיסטוריית הדפדפן. הבקשה דורשת Cookie ואסימון CSRF.
התשובה מכילה רק Id, FirstName, LastName ו-KalpiId, ללא מייל או היסטוריית הצבעה.
החיפוש מותר גם במצב הכנה; הגבלת אישור ההצבעה לזמן הפעילות תיאכף בעת מימוש השמירה.

## בדיקות שבוצעו

```powershell
dotnet build src/KalpiTech.Api --no-restore -p:UseAppHost=false -o .local/stage05-build
.\.venv\Scripts\python.exe -m unittest discover -s tests/voters -p test_voters.py -v
```

הבנייה עברה ללא אזהרות ושגיאות. כל 22 הבדיקות עברו: 12 בדיקות ההתחברות
ו-10 בדיקות חיפוש הכוללות הרשאות, זיוף שיוך, CSRF, אפסים מובילים, קלט פסול,
בוחר חסר, בוחר שכבר הצביע, סדר הבדיקות ואימות שהחיפוש אינו משנה רשומות.
הנתונים נוצרו במסד בדיקה נפרד ונוקו בסיום. אין צורך לשנות הצבעות במאגר הפעיל.
בדפדפן נבדקו חיפוש תקין בקלפי רגילה, שגיאת שיוך וביטול מסך הזיהוי.
קלפי נגישה נבדקה מול ה-API; בדיקת הממשק שלה ומסך צר נשארת לבדיקה ידנית.

[תיעוד הרשאות לפי תפקיד ב-ASP.NET Core 8](https://learn.microsoft.com/en-us/aspnet/core/security/authorization/roles?view=aspnetcore-8.0)
