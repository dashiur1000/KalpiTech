# שלב 13 — דשבורד ועדת הבחירות

המסך **נתוני השתתפות בבחירות** זמין למנהל בלבד ומתעדכן כל חמש שניות. סדר המסך: מצב ומועדים, שישה כרטיסי מצב, גרף קצב שעתי ומצטבר, ערים ומקום ההצבעה בפועל וטבלת קלפיות. הגרפים נבנו ב־HTML, CSS ו־SVG בסיסיים ללא ספריית Frontend.

## API וחישובים

`GET /api/statistics` נשארה נקודת הקצה המרכזית ומוגנת באמצעות `Authorize(Roles = "Admin")`. היא מחזירה DTO אחד: `summary`, `election`, `hourly`, `cities`, `stations`, `votingLocations` וזמן עדכון UTC. אין בתגובה שמות, מספרי זהות, מיילים, כתובות או סיסמאות.

ה־Store מריץ ארבע שאילתות מצטברות בתוך טרנזקציית `RepeatableRead`, ולכן כל האזורים שייכים לאותה תמונת נתונים ואין N+1:

1. סיכום כללי וחלוקת מקום ההצבעה.
2. השתתפות לפי עיר השיוך.
3. נתוני שיוך ופעילות בפועל לכל קלפי.
4. מספר הצבעות בכל שעת UTC.

השעות החסרות בין התחלת הבחירות לזמן הנוכחי או לסיום מוחזרות כאפס. הדפדפן ממיר את חותמות UTC לשעון ישראל. אחוז הוא `Voted / Total * 100`, מעוגל לשתי ספרות; כש־`Total=0` מוחזר `null`. קלפי פעילה נספרת פעם אחת כאשר קיים `VotedIn>0`. קלפי `0` אינה מופיעה בטבלת הקלפיות.

לבקשת המשתמש אזור ההתראות הוסר, כולל התראות על אפס הצבעות ועל זמן ממושך ללא פעילות. טבלת הקלפיות ממשיכה להציג את מספר ההצבעות בפועל ואת זמן הפעילות האחרונה. מידע על ניסיונות התחברות, ניסיונות כפולים ותקלות יחייב בעתיד טבלת `AuditLogs`.

## הרצה

```powershell
docker compose -f compose.yaml -f compose.app.yaml up -d --build --wait
```

פתח http://127.0.0.1:5080, התחבר כמנהל ולחץ **צפייה בנתונים**.

## בדיקות

```powershell
dotnet build src/KalpiTech.Api --output .local/dashboard-build -p:UseAppHost=false
.venv/Scripts/python.exe tests/statistics/test_statistics.py
node --check src/KalpiTech.Api/wwwroot/js/app.js
docker compose -f compose.yaml -f compose.app.yaml build api
```

בדיקות האינטגרציה משתמשות במסד זמני ובנתונים סינתטיים בלבד. הן מכסות הרשאת מנהל, סיכום והנותרים, מאגר ריק, עיר שיוך, שלוש קבוצות מקום הצבעה, שעות חסרות ואפסים, נתוני קלפיות והיעדר שדות אישיים. בדיקות השלבים הקודמים מורצות בירושה.

לאחר הסרת אזור ההתראות עברו 78 בדיקות האינטגרציה המלאות, 16 בדיקות רכיב הטעינה ו־17 בדיקות גבולות זמן ושעון ישראל. הבנייה ב־.NET וב־Docker ובדיקת התחביר של JavaScript הסתיימו בהצלחה. הדשבורד נבדק חזותית ברוחב מחשב וברוחב טלפון ללא גלילה אופקית של הדף.
